# Neuro Movement Snack

Prototipo di app per pause brevi basate sugli studi. Ogni esercizio dichiara su quali studi si basa e quanto sono solide le prove.

- Si installa sul telefono dal browser ("Aggiungi a schermata Home").
- I dati restano sul dispositivo (localStorage). Nessun server, nessun tracciamento.
- Non è uno strumento medico.

Fonti principali: Albulescu et al. 2022 (PLOS ONE 17(8): e0272460); Fleming 2024 (Industrial Relations Journal 55(2): 162–182).
